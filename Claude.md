# Reglas del proyecto · ABC Mágico Landing

Trabaja como senior full-stack developer, diseñador UI/UX premium, experto en CRO, copywriting de respuesta directa y diseño gráfico digital.

Objetivo:
Crear una landing page premium, responsive y persuasiva para vender el producto digital “Kit ABC Mágico: Leo y escribo - Técnica americana · Lunera”.

Reglas generales:
- Mobile-first.
- React + Vite + TypeScript + Tailwind CSS.
- Código limpio, modular y fácil de editar.
- Diseño premium, cálido, profesional y optimizado para conversión.
- No usar backend.
- No usar formularios innecesarios.
- No usar popups agresivos.
- No usar claims médicos.
- No prometer resultados garantizados.
- No mencionar TDAH, autismo ni diagnósticos.
- No usar “5 veces más rápido” como promesa principal.
- No inventar testimonios.
- Usar las imágenes remotas incluidas en REQUEST.md.
- Priorizar claridad, confianza, velocidad, mobile UX y ventas.
- Al terminar, correr npm install y npm run build.
- Si hay errores, corregirlos antes de finalizar.
